# HASTAVA Sourcing Image Specifications

To maintain the luxury B2B aesthetic, please generate/acquire and place the following image assets in the [public/images/](file:///d:/Dev/Projects/thehastava-website/public/images) directory.

---

## Technical Guidelines

*   **Format:** `.jpg` (JPEG) or `.webp` (optimized compression).
*   **Resolution:** Minimum width of **1600px** for landscape and **1200px** for portrait/square frames.
*   **Color Profile:** sRGB with warm, premium, natural lighting (avoid cold studio flashes).
*   **Aesthetic Direction:** Editorial, high-contrast, authentic artisan workspaces, rich heritage textures, zero digital noise/rendering artifacts. No unrelated modern office scenes.

## Image Optimization Standards

To ensure rapid page load speeds, high Lighthouse scores, and optimal UX, the following requirements must be followed during site launch:

*   **Format:** Convert all raster assets to `.webp` format.
*   **Quality Recommendation:** Set compression quality to `80-82%` during export from Figma/Photoshop (maintains visual clarity while drastically cutting size).
*   **Responsive Widths:** Leverage Next.js `<Image>` component `sizes` prop (e.g. `(max-width: 768px) 50vw, 20vw`) to prevent serving oversized images to mobile viewports.
*   **Blur Placeholder:** Use Next.js `placeholder="blur"` with a low-res base64 image (generated during compilation) to prevent layout shifts.
*   **Lazy Loading:** Ensure all images below the fold use `loading="lazy"` (Next.js default behavior). Only the hero collage should use `priority` tag.
*   **Alt Text:** Write descriptive, accessibility-rich alt text detailing the craft and origin (e.g., `"Authentic Bastar Dhokra lost-wax cast brass horse sculpture showing signature clay-thread lines"`).
*   **Next/Image Usage:** Always specify explicit `width` and `height` properties or use `fill` inside relative wrappers to prevent Cumulative Layout Shift (CLS).
*   **Preferred File Size:** All compressed production images must remain under **200 KB** (target < 100 KB for catalog thumbnails).
